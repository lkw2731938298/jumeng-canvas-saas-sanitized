# 第一视角催泪短片导演（技能包）

给画布 AI 助手的配方。用户只在对话里看过程与产物；文件与成片进入项目资产。

| 文件 | 给助手看什么 |
|------|----------------|
| `SKILL.md` | 硬约束、六段节奏、本轮决策、pipeline |
| `references/dialogue-flow.md` | 怎么跟用户说话 |
| `references/demand-checklist.md` | 收题问清什么 |
| `references/script-and-stories.md` | **先写剧本**；定 N 镜；多故事备选；ask |
| `references/pov-emotional-engineering.md` | 情感物 / 重场台词 / 代际翻转 |
| `references/storyboard-prompt.md` | 故事板 userPrompt 怎么写 |
| `references/shot-duration.md` | 总长不固定；尾帧续接下镜 |
| `references/generation.md` | 何时写剧本 / 出板 / 出片 |
| `references/node-layout.md` | 最少节点、批次镜号、连线 |
| `references/canvas-tools.md` | 用哪些系统工具 |
| `references/constraints.md` | 上限总表 |
| `references/failure-and-revise.md` | 改稿与失败 |

流程：收题 → **写细腻剧本（可丰富台词）** → 定节拍/预估总长 + 备选并询问用户 → 出板 → 确认出片 → **单 video 节点出全片**（或超长串行续拍）。**禁止**整板并行挂多镜。
