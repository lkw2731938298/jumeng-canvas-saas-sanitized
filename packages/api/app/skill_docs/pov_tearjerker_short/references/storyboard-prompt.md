# 故事板 userPrompt · 怎么写满每一格

`run_canvas_tool` → `storyboard` / `blocking_storyboard` 时，`params.userPrompt` **必填**。  
本文件规定写法。与 SKILL 冲突时以 SKILL 为准。

## 1. 总结构（推荐整段）

```text
【片名】……
【画幅】9:16（或用户指定）【总时长】不固定，按节拍约 N 镜（用户软目标：……或无）
【风格】写实、克制、第一人称POV，无字幕金句
【情感物】……（贯穿全片）
【无声高潮】第X格……
【代际翻转】第Y格与第1格构图对调：……
【续镜】镜数不固定；单镜秒数不够拆下一格；成片用上一镜尾帧承接
【台词】按用户确认的剧本写入各格对白要点（可丰富，忌口号）

分镜格（按阅读顺序左→右、上→下）：
格1（Xs）：……
格2（Xs）：……
…
【禁止】第三人称全知群戏；产品广告式转圈特写；每格换新道具；煽情旁白字幕
```

## 2. 单格必含 5 要素

每一格用一到两句写清：

1. **第一人称机位**  
2. **谁在画面里、在做什么**  
3. **情感物本格状态**  
4. **运镜一句**  
5. **声音与台词要点**（可写 1～3 句对白摘要；重场可标「片刻静默」）  
6. **标记**：开篇 / 蓄势 / 重场 / 翻转  

可选：光线（清晨侧光、站台冷白等）一句；**不要**堆「8K、泪奔、史诗」。

## 3. 单格句式模板

```text
格{n}（{秒}s）：我的主观视角，{运镜}。{我看到/我的手…}。情感物：{状态}。声音：{…}。{【无声高潮】|【代际翻转】|【开篇】|【蓄势】}。情绪：{一个克制词，如「温」「涩」「静」}。
```

## 4. 完整示例（父爱 · 4 格 · 可改写）

```text
【片名】时光轮轴
【画幅】9:16【总时长】约18s【风格】写实纪录感、第一人称POV、无字幕、无旁白金句
【情感物】旧28式自行车 + 铜钥匙，贯穿全片
【无声高潮】格3：钥匙放入我掌心，无对白
【代际翻转】格4 与 格1 构图对调：我从横杠上的孩子变为骑行的大人

分镜格：
格1（4s）：我的主观视角，跟拍轻摇。我坐在父亲自行车横杠上，看他宽阔的后背穿过林荫路。情感物：自行车第一次承载我。声音：车铃、链条、鸟鸣。【开篇】情绪：稳。
格2（4s）：我的主观视角，缓慢后拉。我自己骑车回头，父亲站在老楼门口越来越小。情感物：车仍在，人渐远。声音：车轮、风声。【蓄势】情绪：涩。
格3（5s）：我的手部特写，慢推。火车站台，父亲把铜钥匙放进我掌心，两人都无对白。情感物：钥匙交接。声音：站台环境、远处列车。【无声高潮】情绪：静。
格4（5s）：我的主观视角，跟拍，构图与格1镜像对称。我骑车，孩子坐在横杠上，阳光从同一方向来。情感物：同一辆车，钥匙在我口袋。声音：车铃、孩子轻笑。【代际翻转】情绪：温。

【禁止】第三人称全知；哭脸大特写；字幕金句；每格更换道具；产品广告式展示
```

## 5. blocking_storyboard 何时用

需要强调**站位/机位关系**（谁左谁右、交接双手位置、镜像构图）时用 `blocking_storyboard`；否则默认 `storyboard`。  
`userPrompt` 仍按本文件写满；可加一句「格1与格4站位镜像对称」。

## 6. 禁止写入 userPrompt 的内容

- 内部 id、工具名、算力说明  
- 「请生成 8K 催泪大片」类空套话  
- 与用户忌讳冲突的元素（用户说不要火车站却写火车站）
