# 约束总表 · 第一视角催泪短片

与 SKILL 冲突时以 SKILL 为准。

| 项 | 要求 |
|----|------|
| 输入 | 人物关系 + 情感主题；缺则先问 |
| 视角 | 第一人称 POV；禁止第三人称群像主路径 |
| 剧本优先 | 出板前必须写好故事：感情细腻、台词可丰富；见 script-and-stories |
| 镜数 | **不固定**；不锁死 4 镜；长视频可 6/8/12+ |
| 出片节点 | **首选 1 个 video 出全片**（总长 ≤ 模型单段上限）；超长才拆 N 段 |
| 参考污染 | **禁止**整板同时连多 video 并行 generate；仅镜 1 可连整板 |
| 多故事 | 关键镜可给 2～3 套演法/故事备选；定镜后 **ask 用户** 再出板 |
| 情绪工程 | 情感物 + 重场 + 代际翻转；允许丰富台词，不强制默片 |
| 单镜时长 | 整数秒；常规 5–12 秒 |
| 总成片时长 | **不固定**；按剧本节拍 |
| 秒数不够 | 截上一镜尾帧 → 作下一镜参考续写 |
| 画幅缺省 | 9:16 |
| 清晰度缺省 | 1080p |
| 主路径 | 故事板合成图 → 视频；禁止分镜表批量主路径 |
| 方案门 | 剧本 + 定 N 镜/N 视频 + 备选 → ask；未同意禁止 storyboard |
| 出片确认短语 | `确认生成` / `开始吧` / `开始生成` / `需要生成` / `提交生成` / `搭线生成` / 点「确认生成」选项 / … |
| 不算确认 | `基于故事板生成视频` / `生成适配` 等 → 须先 ask |
| 已确认 | 禁止再 ask；须同轮 generate |
| 短出片 | 准星 +「生成视频」→ 只出一条 |
| 算力 | 故事板扣生图；未同意出视频不扣视频算力 |
| 成片 | 单节点一次出片，或串行续拍 + 合成一条；禁整板并行多镜 |
| 对话 | 见 dialogue-flow；先故事后人话确认 |

## 确认门速查

```
剧本写好 → 定N镜/备选 → ask「剧本+镜数OK？」→ 同意 → storyboard
出片前 → ask「是否开始生成？」→ 确认短语 → 单节点 generate 或串行续拍（禁整板并行多镜）
```
