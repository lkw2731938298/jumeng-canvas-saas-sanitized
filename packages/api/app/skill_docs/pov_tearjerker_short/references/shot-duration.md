# 时长与续镜 · 总时长不固定 + 尾帧接下一镜

与 SKILL / constraints 冲突时以 SKILL 为准。

## 0. 核心原则（本技能强制）

1. **总成片时长不固定**  
   不按「必须 15s / 必须 30s」硬凑。镜数与每镜秒数由**情绪节拍**决定（起→蓄→无声高潮→翻转/回响），用户指定总长时再贴近用户；未指定则按叙事需要自由组合。

2. **单镜受模型上限约束**  
   单镜 `duration` 仍为**整数秒**，常规 **5–12 秒**（以当前视频模型目录为准）。叙事写不完 → **加下一镜**，不要把单镜拖超上限。

3. **出片方式 · 防参考污染**  
   - 预估总长 **≤ 模型单段上限**（通常 ≤15s）→ **一个 video 节点**，故事板只连此节点一次，prompt 内写全片时间线，**一次** generate。  
   - 总长 **超出** 单段上限 → 拆 N 段，**仅镜 1 连整板**；镜 2+ 只连上一镜尾帧；**串行** generate（禁止整板并行挂多镜）。

4. **秒数不够 → 截上一镜尾帧，参考创作下一镜**  
   当：
   - 单镜时长不够讲完这一拍；或  
   - 下一镜需要与上一镜**动作/空间/情感物状态**连贯  

   则：**截取上一镜头视频的尾帧**，作为下一镜的参考图（首帧/续写参考），再生成下一镜。  
   同批次须写好 `cinematicBatchId` + 递增 `cinematicShotIndex`——系统在镜头生成成功后会**自动截尾帧并连到下一镜**（与电影级宣传片同机制）；助手 plan **不必**手写「截帧」步骤，但方案与话术里要按此逻辑设计与说明。

## 1. 总原则表

| 规则 | 说明 |
|------|------|
| 总时长 | **不固定**；随节拍增减镜数；用户说「大概 15s/30s」时作软目标，可 ± 若干秒 |
| 单镜 | 整数秒；常规 5–12；高潮镜可偏长（仍 ≤ 上限） |
| 写不完 | **拆下一镜** + 上一镜尾帧作参考，禁止硬拉超长单镜 |
| 连贯 | 同批镜号连续；尾帧续接保证运动/物件状态衔接 |
| 下限 | 模型最短若为 5s：草案里更短的标注在落节点时抬到 5，并口头说明一句 |

## 2. 如何拆镜（按剧本节拍，不锁 4 镜）

| 节拍 | 建议 | 时长感 |
|------|------|--------|
| 起 | ≥1 镜 | 常 5–6s |
| 蓄 | **1～N 镜**（长视频主要加在这里） | 各 5–8s；不够再拆 + 尾帧续接 |
| 重场 | 1 镜 | 优先 6–10s |
| 翻转/回响 | 1 镜 | 5–8s |

**镜数示例（非定额）：**

- 短：3～4 镜  
- 常见：5～8 镜  
- 长视频：8～16 镜（或多），用尾帧串成一条成片  

**禁止**默认「只能 4 镜」；用户要长、要细，就加节拍加镜，并在定镜阶段 **ask 确认 N**。

## 3. 尾帧续接下镜（创作逻辑）

```
镜 i 生成成功
    → 截取镜 i 视频尾帧
    → 作为镜 i+1 的参考（通常进 ref_in / 首帧参考）
    → 镜 i+1 的 prompt 承接尾帧画面继续动作或情绪
    → 全部成功后系统按镜号合成一条成片
```

**写下一镜 prompt 时：**

- 明确「承接上一镜结束时的画面：…」  
- 情感物状态与尾帧一致，再推进生命周期  
- 运镜可延续或合理切换，避免无故跳切换场景（除非节拍需要时空跨越，则在草案里标明「时空跳」）

**对用户怎么说（勿念内部字段）：**

> 单镜最长大约十几秒；讲不完我会拆成下一镜，并用上一镜的最后一帧接着拍，这样动作和物件是连贯的。整段总时长不卡死，按故事需要来。

## 4. 用户指定了总时长时

| 用户说 | 做法 |
|--------|------|
| 「大概 15 秒」 | 软目标：优先 3～4 镜，各 5s 左右；略超可接受，先说明 |
| 「大概 30 秒」 | 软目标：4～6 镜；蓄段可多 1 镜 + 尾帧续接 |
| 「一镜到底 30 秒」 | 先建议多镜+尾帧续接再合并；坚持一镜则换支持长时长的模型（若目录有） |
| 「不限时长 / 讲完为止」 | **完全按节拍拆镜**，不压缩高潮 |

## 5. 写入节点

每个 `video_input`：

- `generationOptions.duration` = 该镜整数秒（≤ 模型上限）  
- **同一** `cinematicBatchId` + 递增 `cinematicShotIndex`（从 1 起）——保证自动尾帧续接与成片合并  
- `prompt` 写清本镜节拍；续写镜注明承接上一镜尾帧状态  

助手**不要**在 plan 里虚构「截帧工具名」；续接由系统在同批镜头生成后自动做。若某环境未自动续接，再用画布已有「截取尾帧」能力补连，并对用户说「我把上一镜最后一帧接到下一镜当参考」。
