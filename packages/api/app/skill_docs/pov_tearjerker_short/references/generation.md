# 何时写剧本、定镜、出板、出片

全程用系统工具。  
**先剧本，再定镜问用户，再出板，再出片。**

## 1. 收题

复述关系主题；缺省 9:16 / 1080p；总长与镜数不固定。缺项 `ask_user`。有附件则落参考图。  
**禁止**未写剧本就 `storyboard`。

## 2. 写剧本（`script-and-stories.md`）

1. 片名、梗概、人物小传（感情细腻）。  
2. 分拍剧本：POV 画面 + 内心 + **丰富台词** + 情感物。  
3. 情绪曲线；情感物 / 重场 / 翻转。  
4. 仍**不出板**。

## 3. 定镜定片 + 多故事 → ask

1. 按剧本拆镜：**不锁 4 镜**；长故事多镜。  
2. 写明：共 N 镜 / N 段视频 / 预估总长。  
3. 关键镜给 2～3 套故事备选（过渡镜可 1 套）。  
4. **必须** `ask_user` 确认剧本 + 镜数 + 备选。  
5. 未同意：**禁止** `storyboard`。

## 4. 出板

用户确认后 `storyboard` / `blocking_storyboard`；`userPrompt` 含选定台词与 POV。  
出板成功 → 展示；说明下一步出片扣算力。

已有板且用户未要求重做 → 不要再出第二张板。

## 5. 读板搭镜 → 出片确认

1. 按确认的 N 镜与总长选 **路径 A（单 video）** 或 **路径 B（串行多段）**（见 `node-layout.md` §0–§1）。  
2. **禁止**把整张故事板同时连到多个 video 并并行 generate（参考污染）。  
3. 路径 A：1 个 `video_input`，prompt 内写全片时间线，一次 generate。  
4. 路径 B：N 个 video + 同批 `cinematicBatchId` + 递增镜号；**仅镜 1** 连故事板；镜 2+ 靠尾帧续接；**串行** generate。  
5. 未确认 → `ask_user`。  
6. 已确认 → 按路径 A/B 提交 generate（路径 B 先镜 1，勿同轮并行多镜且各挂整板）。

「基于故事板生成视频」→ 搭镜 + ask，**不要**直接 generate。

## 6. 续接与合成

路径 A：单段即成片。  
路径 B：尾帧接下镜；全部成功后合成一条；对话告知。

## 7. 短出片与失败

准星 +「生成视频」：只出一条。  
失败 / 加镜 / 改台词：见 `failure-and-revise.md`。
