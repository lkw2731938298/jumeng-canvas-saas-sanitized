# POV 情绪工程 · 精细化

用于本技能的剧本、分镜与各镜提示词。与 SKILL 冲突时以 SKILL 为准。

## 0. 一句话定义

用**同一情感物**贯穿全片，人物感情写细，台词可丰富；在接近结尾设一场**重场**（可含片刻静默），再用收束镜与开篇做**角色位置对调**——让观众被细节打动，而不是被口号喊哭。

## 1. 情感物生命周期


选**一件**可触摸、可交接、可磨损的物件（书包、钥匙、饭盒、旧相机、围巾、车票、手表等）。

| 阶段 | 物件状态 | 镜头写法（第一人称） |
|------|----------|----------------------|
| 开篇（童年/起点） | 被给予 / 第一次出现 | 手部特写接过；或物件入画建立关系 |
| 中段（日常积累） | 磨损、陪伴、习惯 | 通勤/并肩，物件入画不抢戏 |
| 高潮前 | 郑重交接或遗留 | 双手交接、空镜桌面、慢推掌心 |
| 收束 | 新主人手中 / 空位 / 「我」递出 | 与开篇构图镜像 |

**硬规则：**

- 全片锁定同一情感物（或「主物件 + 其附属」，如自行车 + 钥匙），禁止每镜换新道具。  
- 禁止把物件拍成产品广告特写（转圈、参数、品牌 Logo 硬推）。  
- 物件名称在草案表「情感物」列每镜写清状态，勿只写一次。

## 2. 重场与台词（可丰富，勿口号）

重场（通常倒数第 2，或收束前一格）仍是情绪顶点，但**不强制整场默片**：

| 要 | 不要 |
|----|------|
| 前后有细腻对白铺垫与回响 | 「我爱你」「保重啊」空喊 |
| 重场中可留 1～3 秒静默（交接/拥抱） | 用旁白解释主题 |
| 口语、口癖、半句、 generational 差异 | 双方轮流演讲 |
| 声音：台词 + 环境音 / 呼吸 | BGM 歌词抢戏（除非用户指定） |

默认推荐：**全片台词偏丰富**，重场「先说清 → 静默动作 → 一句回响」。  
用户明确要默片时，再切回「重场全静默」。

详细剧本与多故事备选 → `script-and-stories.md`。

## 3. 代际翻转

结尾与开篇形成**角色位置对调**（不必换人种，换的是「送」与「被送」）：

| 开篇 | 收束 |
|------|------|
| 大人送「我」 | 「我」送下一代 / 送远行人 / 送当年送我的人 |
| 「我」仰视大人 | 「我」俯视或平视被送者 |
| 接过物件 | 递出同一物件 |
| 「我」在横杠上 | 「我」在骑行位，孩子在横杠上 |

用户明确「不要翻转」时：收束改为**开篇回响**（同一构图、年龄变化或空镜），并在方案里说明。

## 4. 情绪曲线（剧本里写 1 句）

```
起（建立关系+台词）→ 蓄（日常细节，可多节拍）→ 重场（细腻对白+片刻静默）→ 回响（翻转）
```

长视频：在「蓄」中加 2～N 个日常节拍，镜数随之增加，**不锁 4 镜**。

## 5. 主题模板（可套用，勿照抄人名地名）

### 5.1 父爱与传承

- 情感物：旧自行车 / 钥匙 / 手表  
- 弧线：被载上学 → 回望 → 无声交钥匙 → 「我」载下一代  
- 片名备选：时光轮轴、横杠上的风、钥匙温热  

### 5.2 母爱与离别

- 情感物：饭盒 / 围巾 / 手写便签  
- 弧线：清晨被叫醒塞饭盒 → 窗边等待 → 无声整理空房间 → 「我」为她披围巾/送站  
- 忌：夸张哭戏特写  

### 5.3 师生 / 教练

- 情感物：旧讲义 / 哨子 / 签字笔  
- 弧线：仰视讲台 → 并肩改稿/加训 → 无声交还物件 → 「我」站上讲台/场边  

### 5.4 老友 / 同窗

- 情感物：合影 / 车票 / 球鞋  
- 弧线：并肩放学 → 各自轨道 → 无声把合影塞回对方手 → 同一车站反向而行或相送  

### 5.5 异地 / 陪伴

- 情感物：耳机一只 / 旧手机壳 / 航班登机牌  
- 弧线：共用耳机 → 视频通话手持视角 → 无声关机或收起耳机 → 「我」把另一只耳机留给空座位  

选模板后仍须按用户原话改地名、职业、忌讳。

## 6. 写入故事板时的检查清单

出板前自检：

- [ ] 剧本已含细腻人物与台词（或用户只要默片）  
- [ ] 每格都是第一人称机位描述  
- [ ] 情感物每格有状态  
- [ ] 明确哪一格是重场、哪一格是翻转  
- [ ] 无「催泪/泪奔」堆砌词  
- [ ] 单镜时长在 5–12 整数秒；**总长与镜数不硬凑四镜**；写不完已拆多格（尾帧续接）  

详细剧本 → `script-and-stories.md`；`userPrompt` → `storyboard-prompt.md`。
