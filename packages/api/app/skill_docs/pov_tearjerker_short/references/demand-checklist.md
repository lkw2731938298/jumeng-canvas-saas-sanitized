# 收题清单 · 第一视角催泪短片

与 SKILL 冲突时以 SKILL 为准。目标：用最少问题拿齐能做方案的信息；能默认的不要问。

## 1. 必填（缺一则 ask 或从上下文推断）

| 项 | 含义 | 示例 | 缺了怎么办 |
|----|------|------|------------|
| **关系** | 「我」与谁 | 父女、母子、师生、老友 | 必问：和谁的故事？ |
| **情感主题** | 这条片子要传递什么 | 父爱与传承、送别、和解 | 必问：想传达什么情绪/主题？ |
| **时间跨度** | 是否有「从前→现在」 | 童年送学→长大送行 | 未说则默认「有前后对比」并在方案里写明，允许用户改 |

## 2. 可默认（用户未说则用缺省，说了以用户为准）

| 项 | 缺省 | 常见改法 |
|----|------|----------|
| 总时长 | **不固定**（按叙事需要） | 用户说「约 15s / 30s」时作软目标；「讲完为止」则完全按节拍 |
| 画幅 | **9:16** | 16:9、2.35:1（电影感）、1:1 |
| 清晰度 | **1080p** | 用户指定则跟 |
| 镜数 | 按节拍 **3～6 镜**常见；写不完加镜 + 尾帧续接 | 用户指定镜数则优先 |
| 情感物 | 从主题推一件（钥匙/书包/饭盒/围巾…） | 用户指定则锁定 |
| 时代感 | 当代写实，略怀旧 | 用户说年代则跟 |

## 3. 可选增强（有则更好，没有不阻塞方案）

| 项 | 用途 |
|----|------|
| 角色参考图 | 锁人物外形（父亲/孩子/「我」的手等） |
| 场景参考图 | 林荫路、老楼、站台等 |
| 物件参考图 | 情感物外观 |
| 忌讳 | 「不要哭脸特写」「不要旁白」「不要火车站」 |
| 对白偏好 | 默认高潮无对白；用户要一句台词则只放非高潮镜 |

## 4. 提问策略

1. 用户一句话已含关系+主题 → **只复述 + 声明缺省**，不必立刻 ask。  
2. 只给主题没给关系 → 一次 ask：「这段故事里，『我』主要和谁产生情感连接？」  
3. 只给关系没给主题 → 一次 ask：「更想偏传承、送别、和解，还是陪伴？」  
4. **禁止**一轮抛 5 个空填题；最多 1 次 `ask_user`，选项 ≤4 个。  
5. 有图片附件 → 先落 `image_input`，对话里说明「已收到参考，会当人物/道具参考」。

## 5. 收题完成判据

同时满足即可进「方案」阶段：

- [ ] 已知关系对象  
- [ ] 已知情感主题（或用户确认了你的推断）  
- [ ] 已声明画幅（或缺省 9:16）；总时长与镜数：**不固定**（或已记用户软目标）  
- [ ] 情感物：已指定或已有合理默认  
- [ ] 已知用户是否偏好「台词丰富 / 偏克制」（未说则默认台词细腻可丰富）  

然后进入**写剧本**（`script-and-stories.md`），不要直接出板。
