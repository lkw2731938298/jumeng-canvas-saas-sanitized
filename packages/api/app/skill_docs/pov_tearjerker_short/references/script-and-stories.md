# 剧本与多故事备选 · 第一视角催泪短片

与 SKILL 冲突时以 SKILL 为准。  
**出板 / 出片之前**，必须先在对话里写好故事；镜数**不固定为 4**，可为长视频做更多镜。

## 0. 目标

1. 先写出**完整、好看、感情细腻**的剧本（含台词），再谈出板。  
2. 根据剧本**确定几镜、几个视频**，并**询问用户**确认。  
3. 重要镜头可给 **2～3 个故事/演法备选**，让用户选或混搭。  
4. 台词可丰富：日常絮语、半句未说完、 generational 口癖、沉默里的一声称呼——忌空喊「我爱你」口号。

## 1. 顺序（不可跳）

```
收题
  → 写剧本（故事弧 + 人物内心 + 台词）
  → 拆成镜头表（N 镜 / N 个视频；可 >4）
  → 关键镜可附「故事备选 A/B/C」
  → ask_user：确认剧本 + 镜数 + 选用哪套备选
  → 同意后再 storyboard / 出片
```

未完成「剧本 + 定镜定片 + 用户确认」前：**禁止** `storyboard` 与视频 `generate_node`。

## 2. 剧本必须写什么（对话里给人看）

### 2.1 故事头

| 项 | 要求 |
|----|------|
| 片名 | 短、可改 |
| 一句话梗概 | 谁与谁、从哪到哪、主题一句 |
| 人物小传 | 「我」与对方：性格、口癖、怕什么、舍不得什么（各 2～4 句，细腻） |
| 情感物 | 一件贯穿；在剧本里每次出现都有状态 |

### 2.2 分场/分拍剧本（推荐格式）

按时间顺序写 **场次或节拍**（可多于 4）：

```text
【节拍 1 · 开篇】（约 Xs · 建议 1 镜）
画面（POV）：……
「我」内心（可轻声旁白或只写情绪，勿堆砌）：……
台词：
  父亲：（……）
  我：（……）或（沉默 / 只喘一口气）
情感物：……
```

要求：

- **感情细腻**：写具体动作与细节（袖口、钥匙温度、不敢回头的一秒），少用「很感动」「泪流满面」。  
- **台词可丰富**：每场可有 1～4 句对白或半句；口语、 generational 差异、欲言又止。  
- **至少一场「重场」**：交接/送别/翻转；此处可留 1～2 秒静默，但**前后允许有台词铺垫与回响**。  
- 篇幅：短片常见 4～8 节拍；长视频可 8～16 节拍（再拆镜）。

### 2.3 情绪曲线一句

起 → 蓄 → 重场 → 回响（翻转）；长片可在「蓄」里加 2～3 个日常节拍。

## 3. 定镜 · 定视频数（不锁死 4）

剧本写完后，明确告诉用户：

| 项 | 说明 |
|----|------|
| 共几镜 | 按节拍拆；**不固定 4 镜**；长故事可 6 / 8 / 12 镜等 |
| 共几个视频节点 | **首选 1 个**包全片（≤单段上限）；仅超长才 N 段；**禁止** N 节点各挂整板并行 |
| 预估总时长 | 各镜秒数之和（不固定）；说明单段上限与是否需分段 |

拆镜规则见 `shot-duration.md`：单镜写不完 → 加镜 + 尾帧续接。

**示例话术：**

> 按这个剧本，我建议 **N 个节拍**，预估成片大约……  
> **若在模型单段上限内，我会用一个视频节点一次出全片**；更长则分段，只在第一段用故事板定调。

## 4. 每镜多故事备选

对**关键镜**（开篇建立关系、重场交接、翻转收束，或用户点名的镜）提供 **2～3 个故事/演法**：

| 备选 | 写什么 |
|------|--------|
| A | 偏克制：少台词、多动作 |
| B | 偏细腻台词：多半句对白与口癖 |
| C | （可选）时空跳 / 回忆插入 / 另一情感物细节 |

格式示例：

```text
【镜 03 · 重场】建议时长 8s
- 故事 A：站台无声交钥匙；只有环境音与一声「慢点」
- 故事 B：交钥匙前父亲碎碎念旅途注意；我回「你也是」；交钥匙时短暂无声
- 故事 C：改在校门口；台词围绕「钥匙别弄丢」的旧梗
```

用户未选时：默认推荐 **B（台词更细腻）**，并在 ask 里写明。  
**不要**每个镜都强制 3 套（会又臭又长）；次要过渡镜 1 套即可。

## 5. 询问用户（本阶段必须 ask）

剧本 + 定镜 + 备选写完后，**一次** `ask_user`，例如：

> 剧本和镜头规划好了：**共 N 镜 / N 段视频**。  
> 请确认：① 故事与台词是否可用；② 镜数是否 OK；③ 关键镜选 A/B/C 哪套（或「按推荐」）。

选项建议：

- `按推荐出板`（镜数 + 各镜推荐备选）  
- `先改剧本/台词`  
- `增加镜头，做长一点`  
- `减少镜头`  
- `只要文字剧本，暂不出板`

**停。** 未确认前禁止出板。

## 6. 台词写法要点（丰富但不尬）

| 要 | 不要 |
|----|------|
| 具体、口语、可带着情绪停顿 | 「孩子，要记得爸爸爱你」类口号 |
| 重复一件小事（钥匙、饭盒、天气）形成呼应 | 每句都在解释主题 |
| 一方话多、一方话少，显关系 | 双方轮流演讲 |
| 重场前后有铺垫句与回响句 | 全文无对白（除非用户只要默片） |
| 可写字幕级短句，但标明「可烧录/可口播」 | 大段旁白盖过画面 |

第一人称 POV 下：台词可以是「我」听见对方说的，或「我」自己低声说；少用全知旁白。

## 7. 与出板衔接

用户确认剧本与镜数/备选后：

1. 把选定故事写入完整分镜草案表（含台词列）。  
2. `storyboard` 的 `userPrompt` 带上每格台词要点（见 `storyboard-prompt.md`）。  
3. 再走搭镜与出片确认门。
