# 节点布局 · 第一视角催泪短片

画布上只放执行需要的最少节点。用户不在画布上操作；产物以对话和资产为准。

## 0. 参考污染（强制 · 读板出片前必过）

整张故事板合成图含 **N 格画面**。若把**同一张整板**同时连到多个 `video_input` 并**并行** `generate_node`，各镜会「看见」全板所有格，易出现**串镜、跳人物、场景混搭**（参考污染）。

**禁止**：N 个 video 各连整板 + 同轮并行 generate。  
**必须**按 §1 选 **路径 A（单节点）** 或 **路径 B（串行续拍）**。

## 1. 拓扑

### 路径 A · 单 video 节点（首选）

适用：预估成片总长 ≤ 当前视频模型**单段上限**（通常 ≤15s）。

```
[可选：参考图 ×N] → [故事板] → [成片 video ×1] → 资产 + 对话框
```

- 只建 **1 个** `video_input`（名称如「成片」或「全片」）。  
- 故事板（+ 可选参考图）→ **仅此节点** `ref_in`。  
- `prompt` 内按时间线写清各节拍（例：0–5s 开篇…5–10s 蓄…）。  
- `duration` = 总长（≤ 模型上限）。  
- 用户确认后 **一次** `generate_node`。

### 路径 B · 超长 · 串行续拍（仍禁整板并行）

适用：总长 **超过** 单段上限，必须拆 N 段。

```
[可选：参考图] → [故事板] → [镜1 video] → [镜2 video] → … → [镜N video]
                              ↑ 仅镜1连整板          ↑ 镜2+ 只连上一镜尾帧
                全部成功后系统拼接 → [一条成片]
```

| 节点 | type | 建议名称 | 说明 |
|------|------|----------|------|
| 参考图 | `image_input` | 角色参考 / 场景参考 / 物件参考 | 可选；**只连镜 1**（与故事板同批） |
| 故事板 | `image_input` | 故事板 | 合成图产物；**只连镜 1** |
| 镜 1 | `video_input` | 镜1 | 连故事板(+参考)；先 generate |
| 镜 i (i≥2) | `video_input` | 镜{i} | **禁止**连整板；只连镜 i−1 尾帧（系统 `cinematicContinuity` 自动） |

## 2. 位置（避免重叠）

锚点 `(ax, ay)` = 首张参考图；没有则画布中心附近。

| 节点 | 位置 |
|------|------|
| 参考图 k | `(ax, ay + (k-1)*220)` |
| 故事板 | `(ax + 480, ay)` |
| 镜头 i | `(ax + 960, ay + (i-1)*220)` |

## 3. 镜头节点参数

本轮生成一个批次 id（例如 `pov-tear-` + 时间戳），**所有镜头共用**。

每个 `video_input`：

| 字段 | 要求 |
|------|------|
| `prompt` | 该镜第一人称画面 + 情感物状态；与故事板对应格一致；克制情绪词 |
| `cinematicShotIndex` | 从 1 到 N |
| `cinematicBatchId` | 同一批次 id |
| `generationOptions.duration` | 该镜整数秒（常规 5–12；**不要为凑总长超上限**） |
| 画幅/清晰度 | 跟用户或缺省 9:16 / 1080p |

连线：

- **路径 A**：故事板（+参考）→ 唯一 video 的 `ref_in`。  
- **路径 B**：故事板（+参考）→ **仅镜 1** `ref_in`；镜 2～N **不得**连整板。  
- **尾帧续接（路径 B）**：镜 i 成功后系统截尾帧接到镜 i+1；助手勿念字段名，可说「上一镜最后一帧接到下一镜」。

出片顺序：

- **路径 A**：确认后 **一次** `generate_node`。  
- **路径 B**：**串行** generate——先镜 1，尾帧就绪后再镜 2…镜 N（**禁止**同轮并行 generate 且各镜曾挂整板）。本技能对 agent_rules「同轮全部 generate」的**例外**：防污染优先于同批并行。

> 总成片时长 = 各镜之和，**不预设固定总秒数**。秒数不够讲完某一拍 → 增加镜头并用尾帧续写，而不是拉长单镜超限。

## 4. 同轮打包

| 阶段 | 可以一起发的工具 |
|------|------------------|
| 有附件未落点 | 多个 `add_node` 参考图 |
| 出板 | 一次 `storyboard` |
| 同意出片 · 路径 A | 1 个 `add_node` video + `connect_nodes` + 一次 `generate_node` |
| 同意出片 · 路径 B | N 个 video + 仅镜1连板 + **串行** `generate_node`（先 1 后 2…） |

## 5. 已有节点时

- 故事板已在 → 不要重复出板（除非用户要重做板）。  
- 镜头已在且参数正确 → 确认后直接 generate。  
- 镜头已在但未确认 → 只 ask，不要重复搭建。
