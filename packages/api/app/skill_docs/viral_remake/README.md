# 爆款复刻（技能包）

给画布 AI 助手的配方。用户只在对话里看产物；文件与成片进入项目资产。

| 文件 | 给助手看什么 |
|------|----------------|
| `SKILL.md` | 推荐顺序、两道询问、黑盒 |
| `references/generation.md` | 何时分析 / 切段 / 出图 / 出片 |
| `references/node-layout.md` | 最少节点、按段连参考 |
| `references/canvas-tools.md` | 用哪些系统工具 |
| `references/constraints.md` | 5–12 秒整数段与其它上限 |

用户说「复刻这段」「爆款复刻」并上传参考视频后：先分析 → 切段 → 问主体图 → 问成片 → 按段复刻 → 合成一条。
