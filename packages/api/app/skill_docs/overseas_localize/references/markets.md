# 出海目标市场

与对话工具栏一致。调用 `storyboard_overseas_localize` 时写入市场 **id**（如 `US`），不要只写中文名。

| id | 展示 | 对白 | 视觉提示 |
|----|------|------|----------|
| US | 美国 | English | 多元族裔都市感，欧美街景与室内 |
| JP | 日本 | Japanese | 东亚面孔与日系服饰，日本街景/便利店等 |
| KR | 韩国 | Korean | 韩系妆造，首尔街景/咖啡馆 |
| SEA | 东南亚 | English（可带当地味道） | 东南亚面孔与热带街景 |
| EU | 欧洲 | English | 欧洲面孔与欧式街道/室内 |
| MENA | 中东 | Arabic or English | 文化得体，现代都市或沙漠城市 |
| BR | 巴西 | Portuguese | 拉美面孔与活力街景 |
| IN | 印度 | Hindi or English | 印度面孔与城市/市集感 |

用户口头指定「日本版」→ `JP`。会话工具栏已有市场且用户未改口 → 可用该市场。完全没提过 → `ask_user` 确认一次再切段/本地化。
