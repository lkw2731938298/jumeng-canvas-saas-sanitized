# 时长与其它上限 · 一键出海

| 项 | 要求 |
|----|------|
| 目标市场 | 必须先有；id 见 markets.md |
| 切段时长 | **整数秒**；每段 **5–12 秒**（含） |
| 过短 | <5 秒并入相邻段，并入后仍须 ≤12 秒 |
| 过长 | >12 秒按关键点再切，直到每段 ≤12 秒 |
| 参考整片 | 建议 ≤180 秒；更大请用户压缩或先截一段再传 |
| 画幅缺省 | 9:16（用户指定则用用户的） |
| 清晰度缺省 | 1080p |
| 成片提交 | 每段 duration 与切段一致，写进该段 `generationOptions` |
| 算力 | 切段 / 本地化 / 主体图 / 视频分别按对应工具或模型报价；**未同意出视频不扣视频算力** |
| 出视频确认 | `确认生成` / `确认并生成` / `生成同款` / `开始成片` / `批量成片` |
| 产物 | 主体图、各段视频、最终合成片均进入项目资产，并在对话框展示 |
| 文化 | 尤其中东等市场须得体；对白语言与视觉提示见 markets.md |

保留原片节奏与段顺序。用户没说要换的运镜与节奏不要乱改；主体外形与对白必须按目标市场本地化，禁止做成不换市场的原样复刻。
