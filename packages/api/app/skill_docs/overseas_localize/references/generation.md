# 何时分析、切段、本地化、出图、出片 · 一键出海

全程用系统工具。视频出片必须先得到用户口头同意（`ask_user` 或用户已说「生成视频 / 确认生成 / 开始成片」且已看过切段、本地化与主体方案）。

## 0. 市场与参考

| 缺什么 | 先做什么 |
|--------|----------|
| 无目标市场 | `ask_user` 问国家/地区；写入本地化用的市场 id（见 markets.md） |
| 无参考视频 | `ask_user` 请上传；有附件则落 `video_input` |
| 两者都有 | 进入「先分析」 |

用户口头「日本版」与工具栏不一致时，以本轮文字为准。

## 1. 先分析，再切段

| 用户说法 | 先做什么 | 不要做什么 |
|----------|----------|------------|
| 上传了参考 / 「出海做成美国版」 | 看视频，对话里写分析：节奏、关键点、主体名单、建议切成几段、将做哪国版 | 不要还没分析就出片 |
| 分析已经说完 | `storyboard_from_video` 按关键点切段 | 不要把参考原片拿去 `generate_node` |

切段规则（必须执行）：

- 时长 **整数秒**。
- **最短 5 秒，最长 12 秒**。
- 关键点过密导致 <5 秒：并入前一段或后一段，使每段 ∈ [5, 12]。
- 单段仍 >12 秒：再按关键点或均匀切开，每段 ≤12 秒。
- 切完后对用户只报「共 N 段、每段约 Xs」，不要报内部行号。

## 2. 切段后立刻本地化

有切段清单后：

- `run_canvas_tool` `storyboard_overseas_localize`，带上目标市场 id。
- 对白语言、主体人设、场景道具改成目标市场版本。
- 不要跳过本步去做「原片原样」分段复刻。

## 3. 主体图：必须先问

本地化并列出主体后，`ask_user` 示例：

- 问句：已按「{市场}」整理这些主体：……。要不要先生成这些主体的图片，方便后面每段对齐外形？
- 选项：`生成这些主体图` / `先不生成主体图`

| 回答 | 动作 |
|------|------|
| 生成 | `text_subject` 抽出名单（若还没有）→ `storyboard_subject_image` 或对每个主体 `image_input` 出图。外形与服饰按目标市场。等图出现在对话 / 资产后再问成片 |
| 先不生成 | 立刻进入「是否出视频」那一问 |
| 尚未回答 | 停。不出图、不出视频 |

用户要换人换物时：用用户给的参考图落到 `image_input`，再出或替换对应主体图（仍须符合目标市场文化与得体要求）。

## 4. 视频：主体步骤完成后再问

主体图已齐，或用户已跳过出图之后，再 `ask_user`：

- 问句：主体已准备好（或已按你的选择跳过）。要不要按这 N 段生成「{市场}版」视频？全部成功后会自动合成一条成片，产物会出现在对话和资产里。
- 选项：`开始生成视频` / `先不要生成`

未同意：可以改提示词、补主体图，**不能** `generate_node` 视频，不能 `storyboard_batch_videos`。

已同意：见下一节。用户若在问完之后回复「确认生成 / 生成同款 / 开始成片」，视为同意。

## 5. 按段提交（同一轮全部交齐）

同意出视频后：

1. 每段一个待生成的 `video_input`（或分镜表批量工具按行出片）。
2. 该段 `prompt` = 这一段要复刻的动作 / 运镜 / 节奏 + **已本地化**的对白与主体描述（目标市场语言与外形）。
3. 参考：该段**切片视频**（切段工具产出的片段）+ **本段出场的**主体图。不要把整段原片、也不要把未出场主体图接到这一段。
4. `generationOptions.duration` 写成该段整数秒（5–12）。画幅 / 清晰度用用户指定或默认 9:16、1080p。
5. **同一轮**按段顺序调用全部 `generate_node`（或一次 `storyboard_batch_videos` 覆盖全部段）。禁止只交第 1 段、等成功后再交第 2 段。
6. 准星点名参考原片：仍然按段出海复刻，禁止 generate 原片节点。

## 6. 合成一条

各段带同一批次镜号（见 node-layout）。全部成功后系统自动拼接为一条视频，写入资产，并在对话里出现。助手不要再问「要不要合并」，不要再提交下一批。

## 7. 失败

只重试失败的那一段：修该段 prompt / 参考连线后，只 `generate_node` 那个节点。不要把已成功的段再交一次。
