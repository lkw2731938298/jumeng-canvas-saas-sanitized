# 时长与其它上限 · 电影级宣传片

| 项 | 要求 |
|----|------|
| 产品 | 单一产品参考图；缺则先要图 |
| 切段（过长参考视频） | **整数秒**；每段 **5–12 秒**（含） |
| 过短 / 过长 | <5 并入相邻；>12 再切 |
| 30 秒单镜 | 用户明确要求时用 **MiniMax** `rh_minimax_hailuo_h3_r2v`；以模型目录时长上限为准，不足则换支持 30s 的模型或切段后合并 |
| 画幅缺省 | 9:16 |
| 清晰度缺省 | 1080p |
| 成片提交 | 每镜 duration 与故事板规划一致；同批 generate |
| 算力 | 故事板扣生图；**未同意出视频不扣视频算力** |
| 出视频确认 | `确认生成` / `确认并生成` / `生成同款` / `开始成片` / `批量成片`；短出片：准星+「生成视频」 |
| 产物 | 故事板、各镜视频、最终合成片均进项目资产，并在对话框展示 |
| 主路径 | 故事板合成图 → 视频；不要改走分镜表批量成片 |

保留用户指定的卖点与情绪。不要擅自扩成「8K、超写实」套话，除非用户要求润色。
