# 15 秒 / 30 秒怎么拆

| 目标总时长 | 建议 |
|------------|------|
| 约 15s | 故事板 3 格左右，每镜约 5 秒（整数）；或 2 格 6+9 等，单镜仍建议 ≤12s |
| 约 30s | 优先：多镜 5–12 秒整数段，故事板多格，最后合并成一条 |
| 明确要 30s **一镜** | 用 MiniMax（`rh_minimax_hailuo_h3_r2v`）；目录上限不足则换支持 30s 的模型，或拆成 5–12s 多镜再合并 |

有过长参考视频时：先按 5–12s 切段对齐节奏，再出故事板；不要为了「凑 30s」把单镜拖超模型上限。
