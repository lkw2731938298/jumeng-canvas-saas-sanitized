# 何时分析、切段、出板、出片 · 电影级宣传片

全程用系统工具。视频出片必须先得到用户口头同意。

## 1. 先分析需求

对话里写清（缺则 `ask_user`）：

- 产品是什么、核心卖点 / 情绪
- 目标成片时长（常见 15s；可 30s）
- 画幅（缺省 9:16）
- 有无产品参考图、有无参考视频
- 建议几段节奏 / 几格故事板

不要还没分析就出故事板以外的成片；也不要一上来就 `generate_node` 视频。

## 2. 参考视频过长才切段

| 情况 | 动作 |
|------|------|
| 无参考视频 | 跳过 |
| 参考视频不长，可直接当节奏参考 | 可不切，直接进入故事板 |
| 参考视频过长 | `storyboard_from_video` 按关键点切成 **整数秒 5–12** 段 |

切段规则：

- 最短 5 秒、最长 12 秒；过短并入相邻段；过长再切。
- 对用户只报「已切成 N 段」，不要报内部行号。
- 切段结果只作节奏与参考切片；**出片主路径仍是故事板**，不要改走分镜表批量成片。

**30 秒单镜例外**：用户明确要 30 秒一镜到底时，不要按 12 秒上限硬切。用 **MiniMax**（`rh_minimax_hailuo_h3_r2v`）。若模型目录显示该模型最长不足 30 秒，改用目录中支持 30 秒的视频模型，或仍切成 5–12 秒段再合并。

## 3. 推荐流程 → 生成故事板

1. 用一两句话告诉用户推荐的镜次/情绪流程。
2. `run_canvas_tool` `storyboard`（要机位关系用 `blocking_storyboard`）。
3. `params.userPrompt` 写清各格：产品怎么出镜、光影、镜头感；秒数暗示可写在格描述里。
4. 产品参考图作为参考；若有切段切片，可在 prompt 里对齐节奏，不要改用分镜表出片。
5. 板生成成功 → 对话展示产物（进资产）。**停**，询问是否按板出视频（除非用户早已说确认生成）。

已有带图故事板且用户未说「重新生成故事板」→ 不要再出第二张板。

## 4. 参考故事板出对应秒数视频

读板后：

1. 按格（或按约定镜次）建 `video_input`。
2. 每镜 `duration` = 该镜整数秒（常规 5–12；30 秒单镜见上）。
3. 参考：故事板 + 产品图（+ 该镜相关切段参考，若有）。
4. `ask_user`：要不要按故事板生成这 N 镜视频？全部成功后会自动合成一条。
5. 用户同意后，**同一轮**全部 `generate_node`。

未同意：可以改板、改词，**不能**出视频。

用户若在板已展示后直接说「确认生成 / 开始成片 / 出视频」，视为同意。

## 5. 合成一条

各镜同一批次镜号（见 node-layout）。系统自动拼接为一条，写入资产并在对话出现。不要再问「要不要合并」。

## 6. 短出片与失败

- 准星 +「生成视频」：只出一条，禁止再出板、禁止铺多镜。
- 某镜失败：只重试失败镜；不要重交已成功的镜。
