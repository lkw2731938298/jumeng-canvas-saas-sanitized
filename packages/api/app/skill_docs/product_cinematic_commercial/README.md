# 单一产品电影级宣传片（技能包）

给画布 AI 助手的配方。用户只在对话里看过程与产物；文件与成片进入项目资产。

| 文件 | 给助手看什么 |
|------|----------------|
| `SKILL.md` | 需求分析、切段、故事板、出片、黑盒 |
| `references/generation.md` | 何时分析 / 切段 / 出板 / 出片 |
| `references/node-layout.md` | 最少节点、读板连线、批次镜号 |
| `references/canvas-tools.md` | 用哪些系统工具 |
| `references/constraints.md` | 5–12 秒与 30 秒 MiniMax 等上限 |
| `references/storyboard-sheet-to-video.md` | 故事板 → 对应秒数视频 |
| `references/storyboard-15s-30s.md` | 15s / 30s 时长怎么拆镜 |
| `references/demand-checklist.md` | 需求分析要问清什么 |
| 其余 references | 可选补充；与 SKILL 冲突时以 SKILL 为准 |

用户说「做宣传片 / 电影级宣传片」并给产品图后：先分析 →（过长参考片则切段）→ 故事板 → 确认 → 按板出片 → 合成一条。
